빵친구 페스티벌 - 웹사이트 실행 안내

1. ZIP 압축을 풉니다.
2. index.html 파일을 더블클릭하여 브라우저로 엽니다.
3. 상단 '사전등록' 또는 메인 배너의 버튼을 누르면 register.html로 이동합니다.
4. '전체 일정 보기' / '전체 프로그램 보기' 버튼을 누르면 팝업이 열립니다.
5. CSS는 css/style.css, JavaScript는 js/main.js에 분리되어 있습니다.
6. 이미지는 assets 폴더에 실제 PNG 파일로 포함되어 있습니다. 인터넷 연결 없이 표시됩니다.

주의:
- 행사 날짜, 장소, 세부 프로그램은 예시입니다.
- 사전등록은 데모 기능으로 실제 개인정보 저장/전송이 없습니다.
- 제공된 참고 이미지의 권리는 각 원저작자에게 있습니다. 공개 배포/상업적 이용 전 사용 권한을 확인하세요.
